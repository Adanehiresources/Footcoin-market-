# ⚽ FootCoin Market

A multi-page dynamic website simulating a global football player transfer platform.

## Features

- **Home Page** – Hero section, how-it-works, featured superstars
- **Players Market** – Browse 24 world-class players with filters (position, rarity, search, sorting)
- **Earn Coins** – Watch simulated short ads to earn virtual FootCoins
- **My Team** – View your owned players, squad value, stats dashboard

## How to Play

1. You start with **150 coins**
2. Go to **Earn Coins** and watch ads (simulated countdown) to earn more
3. Visit the **Players** page and buy footballers from around the world
4. Check **My Team** to see your collection and statistics

All progress is saved in your browser’s localStorage.

## Tech Stack

- Pure HTML5 + CSS3 + Vanilla JavaScript
- No frameworks or build tools required
- Fully responsive

## How to Run

Simply open `index.html` in any modern browser, or serve the folder with any static server:

```bash
# Example with Python
python -m http.server 8000
```

Then visit http://localhost:8000

## Notes

- This is a **simulation / demo**. No real money, real ads, or real transfers.
- Player data is fictionalized for entertainment.
- Coins and ownership persist only in the current browser.
